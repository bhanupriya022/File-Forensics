Actual File Format Detection

Identifies the true format of a file by reading its binary content — not by trusting its name.

Magic Bytes

The first bytes of every file contain a unique signature. File Forensics checks against 40+ known signatures covering images, documents, executables, archives, audio, video, fonts, and more.

Container Refinement

ZIP-based formats (DOCX, XLSX, PPTX, ODF, JAR) are identified by inspecting the ZIP entry list. RIFF containers (WAV, AVI, WebP) are distinguished by their 4-byte tag at offset 8.

Text Heuristics

When no binary signature matches, a printable-byte ratio test is applied. Matching content is further classified as HTML, XML, JSON, Python, Shell, CSS, JavaScript, or CSV.

Supported Formats

Risk Assessment

Each file is scored 0–100 based on its detected format, extension mismatch, and disguise pattern. Scores map to SAFE / LOW / MEDIUM / HIGH.

+50 pts — Extension Mismatch

The declared extension does not match the actual detected MIME type.

+40 pts — Executable / Script

Detected format is a Windows PE, ELF binary, Mach-O binary, shell script, or batch file.

+20 pts — Archive / Database

Detected format is a compressed archive (ZIP, RAR, 7Z, TAR, GZ) or SQLite database.

+10 pts — Dangerous Disguise

A high-risk format (e.g. PE executable) is disguised as a common benign extension (.pdf, .jpg, .txt).
